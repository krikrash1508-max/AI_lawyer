1 · Process

How an NDA gets approved today, and with Klauzula

The lawyer still decides at every point. Klauzula removes the manual comparison with the company's rules and the manual search for what changed between versions.

Today

→
QueueWaits about 2 days for the lawyer
→
LawyerReads all of it, checks rules from memory
→
LawyerEdits in Word, explains by email
→
SalesSends the edits to the counterparty
→
New versionSales forwards it, it waits in the queue again, the lawyer finds changes by hand

↺ Every round of negotiation goes back through sales and the queue.

KlauzulaMasks identifiers: email, phone, PESEL, NIP, KRS, IBAN
→
KlauzulaChecks 10 playbook rules: OK / Review / Red flag

Lawyer decidesRed flags: edits, accepts or rejects each proposal

2 · Name and visual style

Klauzula: the Polish word for a contract clause

We are a tool for the lawyer, not an "AI lawyer", so the name speaks the lawyer's language. The mark is a § in a circle, like the ink of an official stamp. The screen is a lawyer's desk: the contract on a sheet in a serif face on the left, findings on the right.

5 · Observations from building v0.1

What we learned

Rules get far on standard NDAs

Ten pattern rules caught all six red flags in the sample. They will miss unusual wording, so the AI mode is for robustness, not for the demo.

Compare is the strongest moment

Version 2 fixed five problems and quietly added an indemnity. The tool shows it in one line. A lawyer comparing by hand can easily miss it.

Masking has a gap

Identifiers are masked, but the name of the company's representative is not. People's names need a proper recogniser before a pilot.

The playbook is the product

Quality depends on rules written by a lawyer. Ours are examples. A radca prawny has to check them before any interview demo.

Lawyers live in Word

Export for Word works, but real tracked changes inside the .docx matter more than any screen. This is the first thing to build after v0.1.

No AI results yet

The Claude mode is written to the same output format but has not run on the test set. Accuracy numbers come next, in the prompt log.
